# Security policy

## Supported versions

Security fixes currently target the latest TypeFlow release.

## Reporting a vulnerability

Please use a [private GitHub security advisory](https://github.com/0hEve/typeflow/security/advisories/new).
Do not open a public issue for vulnerabilities that could expose user text or
cause unprompted keystroke injection.

Include the affected version, macOS version, reproduction steps, impact, and any
suggested mitigation. Please avoid including private text or credentials in the
report.
